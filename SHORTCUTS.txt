EditMdView 完整快捷键清单
========================

适用范围
--------
“插件”表示 EditMdView 自己处理的快捷键，在相应的编辑/预览模式下可用。
“编辑区”表示 Scintilla 5.6.6 的 Windows 默认键位，仅当编辑区拥有焦点时可用。
本清单以插件当前实际编译的键表为准；不包含 SciTE 菜单中另行定义、但 Scintilla 本身没有的快捷键。

插件：文件、模式与查找
----------------------
Ctrl+S                  保存当前文件
Ctrl+Shift+S            另存为；成功后当前窗口切换到新文件
Ctrl+M                  Markdown/HTML 循环切换：预览 → 编辑 → 分栏 → 预览
Ctrl+F                  聚焦顶部查找框；已有单行选区时自动填入选中文字
Ctrl+H                  打开非模态“查找和替换”窗口；已有单行选区时自动填入选中文字
Ctrl+G                  跳转到指定行
Ctrl+Shift+R            立即重新加载 SciTE 配置；配置文件修改后也会自动重新加载
F3                      查找下一个
Shift+F3                查找上一个

Markdown 格式（仅 Markdown 编辑/分栏模式）
-----------------------------------------
Ctrl+B                  加粗；添加或取消 **文字**
Ctrl+I                  斜体；添加或取消 *文字*
Ctrl+Shift+H            高亮；添加或取消 ==文字==
Ctrl+Shift+X            删除线；添加或取消 ~~文字~~
Ctrl+K                  插入 [文字](链接地址)；有选区时将选区作为链接文字
Ctrl+`                  行内代码；添加或取消 `代码`
Enter                   列表、编号、任务列表和引用自动续写；空项目退出当前结构
Tab / Shift+Tab         增加或减少列表、任务和引用的层级
输入成对符号            自动补全 ()、[]、{}、引号和反引号；有选区时同时支持 *、_、~ 包裹
在选区上粘贴 URL       自动生成 [选中文字](URL)
/                       在空白行或行首缩进后打开 Markdown 快捷命令面板
Up / Down               在快捷命令面板中选择命令
Enter / Tab             执行选中的快捷命令
Esc                     关闭快捷命令面板

Markdown 斜杠命令
-----------------
/h1 /h2 /h3             一级、二级、三级标题
/l1 /l2 /l3             无序列表、有序列表、任务列表
/code                   围栏代码块
/quote                  引用
/table                  表格；选择后设置行数和列数
/v1 或 /note            注释提示块
/v2 或 /important       重要提示块
/v3 或 /tip             提示信息块
/v4 或 /warning         注意警告块
/v5 或 /caution         警告提示块
/link                   Markdown 链接

顶部查找框
----------
Enter                   查找下一个
Shift+Enter             查找上一个
Shift+Delete            删除下拉列表中当前选中的查找记录
Esc                     返回当前预览或编辑区域

编辑区：常用编辑
--------------
Ctrl+Z                  撤销
Ctrl+Y                  重做
Alt+Backspace           撤销
Ctrl+X                  剪切
Shift+Delete            剪切
Ctrl+C                  复制
Ctrl+Insert             复制
Ctrl+V                  粘贴
Shift+Insert            粘贴
Ctrl+A                  全选
Delete                  删除选区；无选区时删除下一个字符
Backspace               删除上一个字符；根据配置可执行反缩进
Shift+Backspace         与 Backspace 相同
Insert                  切换插入/覆盖模式
Enter                   插入换行
Shift+Enter             插入换行
Tab                     缩进；自动补全打开时接受当前候选项
Shift+Tab               减少缩进
Esc                     取消自动补全、调用提示等 Scintilla 临时状态

编辑区：行、选区与大小写
----------------------
Ctrl+D                  复制选区；无选区时复制当前整行
Ctrl+L                  剪切选区所涉及的整行；无选区时剪切当前行
Ctrl+Shift+L            删除选区所涉及的整行；无选区时删除当前行
Ctrl+Shift+T            复制选区所涉及的整行；无选区时复制当前行
Ctrl+T                  将当前行与上一行互换
Ctrl+U                  将选区转换为小写
Ctrl+Shift+U            将选区转换为大写
Ctrl+Delete             删除到下一个单词边界
Ctrl+Backspace          删除到上一个单词边界
Ctrl+Shift+Delete       删除从光标到行尾的内容
Ctrl+Shift+Backspace    删除从行首到光标的内容

编辑区：光标移动与普通选择
------------------------
Left / Right            向左/右移动一个字符
Shift+Left / Right      向左/右扩展选区一个字符
Ctrl+Left / Right       向左/右移动一个单词
Ctrl+Shift+Left / Right 向左/右扩展选区一个单词
Ctrl+/                  移到上一个单词组成部分（适合 camelCase 等标识符）
Ctrl+Shift+/            向左按单词组成部分扩展选区
Ctrl+\                  移到下一个单词组成部分
Ctrl+Shift+\            向右按单词组成部分扩展选区
Up / Down               上移/下移一行
Shift+Up / Down         向上/下扩展选区一行
Ctrl+Up / Down          编辑区视图向上/下滚动一行，尽量保持光标位置
Ctrl+[                  移到上一段
Ctrl+Shift+[            扩展选区到上一段
Ctrl+]                  移到下一段
Ctrl+Shift+]            扩展选区到下一段
Home                    移到行首；开启 wrap.aware.home.end.keys 时按可视换行处理
Shift+Home              扩展选区到行首；可受上述配置影响
End                     移到行尾；开启 wrap.aware.home.end.keys 时按可视换行处理
Shift+End               扩展选区到行尾；可受上述配置影响
Alt+Home                移到当前屏幕可视行的开头
Alt+End                 移到当前屏幕可视行的结尾
Ctrl+Home               移到文档开头
Ctrl+Shift+Home         扩展选区到文档开头
Ctrl+End                移到文档结尾
Ctrl+Shift+End          扩展选区到文档结尾
PageUp / PageDown       向上/下翻页
Shift+PageUp/PageDown   向上/下翻页并扩展选区

编辑区：矩形（列）选择
----------------------
Alt+Shift+Left/Right    向左/右扩展矩形选区
Alt+Shift+Up/Down       向上/下扩展矩形选区
Alt+Shift+Home          将矩形选区扩展到行首
Alt+Shift+End           将矩形选区扩展到行尾
Alt+Shift+PageUp        向上翻页并扩展矩形选区
Alt+Shift+PageDown      向下翻页并扩展矩形选区

插件与编辑区：显示
------------------
Alt+Z                   切换自动换行
状态栏“自动换行/不换行”  单击切换换行模式，并保持光标和窗口位置
Ctrl++                  放大编辑区字体（主键盘加号）
Ctrl+-                  缩小编辑区字体（主键盘减号）
Ctrl+0                  恢复编辑区缩放
Ctrl+Num+               放大编辑区字体
Ctrl+Num-               缩小编辑区字体
Ctrl+Num/               恢复编辑区缩放（Scintilla 默认键位）
Ctrl+鼠标滚轮           放大或缩小编辑区字体

非模态“查找和替换”窗口
----------------------
Tab / Shift+Tab         在窗口控件间向前/向后移动焦点
Enter                   执行当前操作；查找框中为“查找下一个”，替换框中为“替换”
Shift+Delete            删除查找或替换下拉列表中当前选中的记录
Esc                     关闭查找和替换窗口
“查找下一个”           按“向上查找”选项定位上一处或下一处匹配
“替换”                 替换当前匹配并继续查找
“全部替换”             一次完成替换，可通过 Ctrl+Z 整体撤销

预览与分栏交互
------------
Ctrl+F                  在渲染内容中查找；分栏模式同时定位源码和预览
F3 / Shift+F3           查找下一个/上一个
                        预览中会高亮全部匹配，当前项使用强调色，状态栏显示“当前/总数”
单击渲染内容            分栏模式下反向定位到对应源码；拖动选择文字时不跳转
单击标题刻度            跳转到相应 Markdown 标题
拖动正文边缘调节区      调整 Markdown 预览正文宽度，并保持正文居中
拖动分栏中线            调整源码与预览的宽度；双击中线恢复各占一半
代码块右上角按钮        复制完整代码；有语言标记时同时显示语言名称和语法高亮

补充说明
--------
替换窗口保持打开时仍可继续编辑正文。
顶部查找框和替换窗口均可下拉选择最近使用内容；查找、替换各保留 20 条并自动去重。
历史保存在插件根目录的 EditMdView.history.ini；该文件运行时自动创建，不随安装包覆盖。
未编辑的文件被外部程序修改后会自动重新载入；存在本地修改时只提示，不会覆盖编辑内容。
光标、选择范围、编辑/预览滚动位置、查看模式和分栏比例会按文件保存，并在下次启动时恢复。
未保存内容会自动写入 %LOCALAPPDATA%\EditMdView；异常关闭后再次打开文件时可选择恢复，正常保存或明确放弃后自动删除。
256 KB 至 8 MB 的 Markdown/HTML 在后台生成预览；状态栏会显示生成状态，超过 8 MB 时暂停实时预览。
插件会拦截 Ctrl 组合键产生的不可见控制字符，因此 Ctrl+D、Ctrl+U 等 Scintilla 默认命令不会向正文插入乱码。
不同键盘布局可能要求配合 Shift 输入 /、\、[、]、+ 等符号；上表按 Scintilla 的逻辑键名书写。
